# Патч 0.5.0 поверх 0.4.0

Перед обновлением сохраните рабочий проект. Распакуйте содержимое архива в корень репозитория с заменой файлов. Патч содержит src, тесты, package.json и документацию; удалений нет. Установка пакетов не нужна.

Локально: npm test, затем npm run dev. После загрузки изменений в GitHub на VPS:

```bash
(
set -eu
cd /opt/scheduler
git pull --ff-only
test -f src/excel-layout.js
test -f src/excel-template.js
cp index.html /opt/moonkeeper-site/scheduler/
cp -R src public /opt/moonkeeper-site/scheduler/
)
```

Обновите страницу Ctrl+F5. Перезапуск Caddy не нужен.

JSON сохраняется под названием расписания; в поддерживаемых браузерах — через системное окно с подтверждением замены существующего непустого файла. Для других браузеров сохраняется обычная загрузка, с ограничениями, описанными в README.

Excel использует оформление кафедрального шаблона. Полное восстановление возможно через «Открыть», если сохранён служебный лист `_PROJECT`. Ручные изменения видимой сетки не меняют снимок проекта.
