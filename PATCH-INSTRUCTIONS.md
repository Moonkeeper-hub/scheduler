# Патч 0.4.0

Накопительный патч для Moonkeeper Schedule 0.2.0 и 0.3.0. Содержит необязательные поля импорта и весь функционал 0.3.0: последовательные пары через неделю, среднюю нагрузку групп, синхронные подгруппы и объединение с подтверждением/отменой.

1. В работающем редакторе нажмите «Сохранить проект» и сохраните JSON.
2. Остановите локальный сервер (Ctrl+C в терминале).
3. Распакуйте содержимое этого архива в корень проекта — туда, где уже находятся package.json, src и index.html. Подтвердите замену файлов. Новую вложенную папку создавать не нужно.
4. Запустите `npm.cmd run dev` на Windows или `npm run dev` в другом терминале. Обновите вкладку через Ctrl+F5.
5. Откройте сохранённый проект, если автокопия не восстановилась.

Git и установка новых npm-пакетов не нужны. Для GitHub загрузите заменённые исходные файлы в существующие папки репозитория. Файлы реального расписания не добавляйте.

В архиве также есть обновлённые dist/src для статической сборки. Полностью пересоздать сборку можно через `npm run build`. Если приложение запущено Docker, пересоберите контейнер: `docker compose up -d --build`.

## Импорт

Обязательно сопоставлять только ФИО / шифр группы / название аудитории. Для всех остальных колонок можно оставить «— выбрать —», либо импортировать пустые ячейки. Явно некорректные значения (например текст вместо числа мест) по-прежнему дают ошибку. Пустые значения не превращаются в нули или нормативы.

Форма незаполненной группы открывается из очереди; нужные свойства можно дополнить позже. Неуказанный день и неделя остаются неизвестными. Для гибкости явно укажите «любой» день или используйте кнопку в карточке.

Формат проекта schema 1 сохранён. Существующие заполненные карточки не очищаются. Повторный импорт пока добавляет карточки и не обновляет автоматически совпадающие имена — для этого редактируйте существующую карточку.
