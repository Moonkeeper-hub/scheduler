# Мастер расстановки — версия 0.7.1

Перед экспериментами сохраните JSON-проект. Мастер расположен на вкладке «Редактор», вызывается красно-жёлтой кнопкой. Выберите день или несколько дней, при необходимости — группу или группы одного преподавателя.

## Первый запуск

1. Импортируйте группы, преподавателей, аудитории; уточните численность, деление и нормы.
2. В карточках преподавателей задайте недоступные и нежелательные пары, желаемые и запрещённые группы (шифры через запятую).
3. Откройте мастер, выберите дни. Для первого заполнения используйте «Дополнить»: все существующие назначения сохраняются.
4. Выберите время поиска (4, 15 или 30 секунд; по умолчанию 15) и нажмите «Рассчитать вариант». Во время расчёта виден счётчик обработанных задач. В предпросмотре видны новые и изменённые назначения, нераспределённые группы с причинами, аудитории и показатели до/после.
5. Примените вариант, проверьте сетку вручную. Применение — одно действие отмены; расчёт можно закрыть без изменения проекта.

Мастер работает в Web Worker, его можно отменить. Он ищет несколько вариантов с ограничением времени, а не гарантированный математический оптимум. При достижении лимита показывает частичный результат с предупреждением. На тесте из 60 групп трёх предоставленных файлов, с 25 вымышленными преподавателями и 12 аудиториями, получено 112 назначений без жёстких конфликтов; это проверка масштаба, а не обещание результата на реальных ограничениях кафедры.

## Что учитывает мастер

- Допустимые дни, пары и чётность недель; преподаватель и аудитория не могут пересекаться.
- Подгруппы одного занятия идут одновременно у разных преподавателей. Для одной подгруппы сохраняется один преподаватель на разных занятиях.
- Однозначные соседние пары через неделю обрабатываются блоком. Уже частично назначенные блоки дополняются с проверками.
- Запреты групп и недоступное время — обязательные условия.
- По умолчанию нельзя превышать заданную норму. При необходимости этот флажок можно снять. Пустая норма не ограничивает нагрузку.
- Аудитории подбираются по вместимости. Если подходящих помещений нет, назначение остаётся с пометкой «Требуется аудитория».

Оценка варианта штрафует окна, дополнительные приезды, короткие дни из 1–2 пар, превышение желаемого числа дней и нежелательные пары; учитывает пожелания групп и старается избегать лишних изменений. I и II недели оцениваются отдельно. «Желательно не более дней» — пожелание, не жёсткий запрет: допустимый результат может его превысить. Отсутствие окон не гарантируется, если слоты или доступность этого не позволяют. Мастер не создаёт новые временные слоты и не переносит пары в свободные ячейки без согласования.

## Изменение готового расписания

### Уточнили численность, группу больше не делят

Откройте карточку группы, измените численность, снимите деление и выберите, преподавателя какой подгруппы оставить. Предпросмотр покажет, какие назначения сохранятся и какие удалятся. Преподаватель оставшейся подгруппы сохраняется; вместимость помещения проверяется заново с предупреждением. Само изменение численности не отключает деление, кроме случая одного студента.

### УМУ изменили время

Можно изменить время в карточке группы или повторно импортировать новый файл УМУ. Существующие группы сопоставляются по шифру; фактическая численность и деление сохраняются. При однозначном изменении времени сохраняются ID занятий и преподаватели обеих подгрупп. Если назначение конфликтует, в очередь возвращается только затронутая часть, без удаления других групп. Неоднозначное сопоставление не угадывается: старые назначения снимаются в предпросмотре, новые занятия ждут расстановки. При импорте двух изменённых групп взаимодействие проверяется последовательно; последующая перерасстановка может улучшить результат.

Удалённые из нового файла группы автоматически не удаляются. Численность и деление из повторного УМУ не заменяют ручные данные. Перед применением проверяйте список последствий.

### Преподаватель попросил перенести пары

В панели выбранной группы нажмите «Перенести». Блок пар и обе подгруппы переносятся вместе; можно сменить преподавателя выбранной подгруппы блока. Если есть полная занятость УМУ, показаны свободные места группы с учётом длины блока. Время за пределами согласованных вариантов требует явного флажка согласования с УМУ. Конфликт с другой дисциплиной или преподавателем блокирует перенос. Без исходного УМУ занятость по другим дисциплинам нужно проверить вручную.

Альтернативный путь: измените недоступность преподавателя. Предпросмотр вернёт в очередь только его конфликтующие занятия; дальше запустите мастер для нужных дней или групп.

### Нужно улучшить часть расписания

Нажмите «Закрепить» у назначений, которые нельзя менять мастеру. Закрепление одного занятия защищает всю группу от автоматической перерасстановки. Выберите режим «Перерасставить» и нужные дни/группу. Вне выбранного диапазона назначения сохраняются. Закрепления не запрещают осознанное ручное изменение: предпросмотр отдельно предупреждает о нём.

В редакторе, в разделе проверок, хранится краткий журнал последних изменений. Подробное восстановление доступно через отмену в текущем сеансе и сохранённые JSON-проекты.

## Исправление производительности 0.7.1

В 0.7.0 предварительный перебор мог исчерпать четырёхсекундный лимит до первого назначения на проектах с 200+ группами. Предварительная оценка упрощена; оценка кандидата теперь пересчитывает только расписание затронутого преподавателя. Расчёт окон использует отдельную сетку I/II недель. Добавлены прогресс, выбор времени поиска и отдельные объяснения незаполненных карточек и необработанных из-за лимита задач. При прерванной перерасстановке корректное исходное расписание сохраняется, если найденный вариант содержит меньше назначений.

Поиск выполняется одним Web Worker в браузере пользователя; установленный лимит не связан с ресурсами VPS. Проверка масштаба: 220 групп, 75 вымышленных преподавателей, 30 аудиторий и 35 существующих назначений. В контрольном запуске вся неделя обработана примерно за 3 секунды; время на другом компьютере может отличаться.
