# Moonkeeper Schedule

Локальный редактор семестрового расписания кафедры английского языка. Один составитель, файлы проекта на его компьютере, VPS раздаёт только статические файлы. Версия 0.6.0.

## Запуск

Требуется Node.js 20 или новее. Установка npm-пакетов не нужна.

```bash
npm run dev
```

Откройте http://localhost:5173. На Windows команды выполняются из распакованной папки (при ограничениях PowerShell можно использовать `npm.cmd run dev`).

```bash
npm test
npm run build
```

`dist/` — готовая статическая сборка. Можно разместить на любом статическом хостинге. Не открывайте index.html двойным кликом через file://: приложение использует ES-модули.

## Рабочий процесс

1. Изучите демонстрационные данные. Это вымышленные назначения, а не импорт кафедральной таблицы.
2. Сохраните демо или нажмите «Новый».
3. В разделах «Преподаватели» и «Аудитории» создайте карточки. У преподавателя отдельно задаются ставка и индивидуальная норма пар в неделю; автоматической привязки должности к норме нет.
4. Импортируйте исходные группы или добавьте их вручную. В «Импорт» есть образец CSV. На одну строку приходится одно обязательное занятие; несколько строк одной группы — несколько занятий.
5. У группы могут быть альтернативные слоты: отредактируйте занятия в её карточке обычными списками дней, пар и недель. `options` одного занятия — варианты на выбор, разные объекты массива — отдельные обязательные занятия. В интерфейсе JSON не показывается. Кнопка «Любой день на этой паре» создаёт варианты на всю неделю.
6. Выберите карточку в верхней очереди. Уточните численность и, если больше 24 человек, включите деление. Укажите вариант слота и подгруппу. Назначьте преподавателя и аудиторию через панель или перетащите карточку на строку преподавателя в нужной паре.
7. Подгруппы одного занятия размещаются одновременно и у разных преподавателей. Изменение деления удаляет прежние назначения после подтверждения. Изменение численности само по себе деление не включает и не выключает (кроме невозможного размера подгрупп).
8. Занятия с I/II неделями проверяются раздельно. Средняя нагрузка: еженедельная пара = 1; пара через неделю = 0,5.
9. Клик по назначению выбирает его группу; удалить назначение можно справа. Для переноса удалите прежнее назначение и назначьте заново. Отмена/повтор хранят 40 действий в пределах сеанса.
10. Группа уходит из очереди только после назначения всех занятий всех подгрупп. «Отложить» переносит её в конец.

## Сохранение и восстановление

- **Сохранить проект** — JSON со всеми карточками, вариантами, ограничениями, исходными строками импорта и назначениями. Это основной переносимый файл.
- **Excel** — преподаватели, группы, аудитории, назначения, сводная сетка и служебный лист `_PROJECT`. Открытие такого файла восстанавливает состояние из `_PROJECT`.
- **Важно:** правки видимых листов экспортированного Excel НЕ меняют встроенный снимок `_PROJECT`. Для редактирования с восстановлением используйте приложение. Служебный лист не удаляйте. Это намеренно обозначенное ограничение v0.1.
- Автоматическая копия хранится в `localStorage` текущего профиля браузера на текущем домене. Она загружается при следующем открытии. Очистка данных браузера удаляет копию; скачивайте проект регулярно. В приватном режиме сохранность не гарантируется.
- «Новый» создаёт пустой проект и заменяет локальную автокопию после подтверждения. Сначала скачайте предыдущую работу.

## Просмотр преподавателями

«Для просмотра…» создаёт JSON с ФИО и занятиями, без норм, пожеланий, численности и нераспределённой очереди. Передайте файл по принятому кафедрой каналу. Преподаватель открывает `https://ваш-домен/#view`, нажимает «Открыть файл публикации», выбирает себя. Файл обрабатывается в памяти; запоминается только выбранный преподаватель. После перезагрузки публикацию нужно открыть снова. Есть печать и мобильная компоновка.

Публикация не загружается на VPS. На сайте нет общей актуальной версии для всех: обновлённый файл нужно распространить повторно. Просмотр текущего проекта без открытия публикации помечен как предварительный.

## Импорт

Поддерживаются JSON-проекты, Excel-снимки приложения, а также XLSX/XLS/CSV с заголовками. После открытия выберите тип: группы и занятия, преподаватели (ФИО, должность, ставка, норма пар/нед.) или аудитории (название, вместимость). Обязательно только ФИО преподавателя, шифр группы или название аудитории. Все остальные поля могут быть пустыми. Выберите лист и сопоставьте нужные столбцы. До применения доступен предпросмотр и список ошибок. Все ошибки блокируют применение. Исходная строка и её номер сохраняются у импортированного занятия. Карточки с уже существующим кодом или именем блокируют повторное добавление. Пустой день остаётся неизвестным. Для любого дня укажите «любой» или «*».

**Не реализован универсальный парсер матричных расписаний учебных отделов.** Для таких файлов нужен отдельный адаптер после изучения реальных образцов. Не реализовано сравнение повторных импортов; текущая версия не перезаписывает ручные назначения автоматически.

## Проверки

Блокируются: пересечения преподавателя и аудитории, дубли одной подгруппы, неподходящее время, разные часы подгрупп одного занятия, один преподаватель у двух подгрупп, явно запрещённая пара. Нежелательное время, нехватка мест, превышение нормы и отсутствие аудитории требуют подтверждения. После изменения карточек проверяйте раздел конфликтов.

## Границы первой версии

- Нет автоматического решателя, календарных исключений, периодов внутри семестра, учёта праздников и переходов между корпусами.
- Нет профилей импорта сложных матриц и повторного импорта с сопоставлением версий.
- Формы групп, преподавателей и аудиторий используют обычные поля. Запреты и нежелательные пары отмечаются в раскрывающихся таблицах галочками; «Весь день» отмечает семь пар.
- Режим сетки — по преподавателям, один день или вся неделя. Отдельной сетки занятости аудиторий пока нет.
- Немецкий, французский, китайский не включены в специальную логику.
- Приложение рассчитано на один браузер одного составителя, без синхронизации между устройствами.

## Данные и приватность

Нет API, аналитики, cookies, веб-шрифтов или внешних CDN. SheetJS включён локально. CSP запрещает `connect-src` и внешние скрипты. Документы не отправляются серверу. Обычный веб-сервер всё равно видит запросы статических файлов и IP посетителей; настройка ниже отключает access log nginx. Файлы проектов и публикаций содержат персональные данные: способ их передачи и хранения выбирает кафедра. Автокопия доступна любому, кто пользуется тем же профилем браузера.

## VPS / Docker / Caddy

Пример использует свободный локальный порт 8092. При необходимости измените его.

```bash
docker compose up -d --build
```

В существующий Caddyfile добавьте (поддомен предварительно направьте DNS-записью на VPS):

```caddy
schedule.moonkeeper.ru {
    reverse_proxy 127.0.0.1:8092
}
```

Проверьте конфигурацию Caddy и перезагрузите его принятым на вашем сервере способом. Если Caddy работает в контейнере, `127.0.0.1` относится к самому контейнеру: подключите сервисы к общей Docker-сети и используйте `reverse_proxy schedule:80`.

- У целой группы нет подписи «1 п/г». В публикациях версии 0.1 отсутствует признак деления: откройте исходный проект и сформируйте файл просмотра заново.
- «Для просмотра…» — прежний файл публикации: только расписание и ФИО, без рабочих параметров. Не заменяет сохранение проекта. Интеграция с Google Docs пока не реализована.

## Изменения 0.3.0

- Импорт принимает типы недели «чётная», «нечётная», «обе», а также I, II, both. В этой версии I соответствует нечётной неделе, II — чётной.
- Для импорта используйте первый лист «Слоты» исправленного файла групп: Группа, Численность, День, Пара, Неделя, Подгрупп. В окне импорта сопоставьте обязательные поля; «Подгрупп» — необязательное поле «Число подгрупп». Численность можно заполнить после импорта по фактическим данным.
- Каждая пара занимает отдельную строку. Две соседние пары одной группы на одном дне одной чётной/нечётной недели назначаются одним блоком, если сосед однозначен. Дубли подгрупп в одном слоте не создают лишних занятий. Указание второй подгруппы или числа подгрупп 2 сохраняет деление. Распределение численности между подгруппами после импорта первоначально равное; уточните в карточке.
- В блоке одновременно проверяются преподаватель и аудитория на обеих парах. Если одна пара недоступна, весь блок остаётся неназначенным. Нагрузка преподавателя: две пары через неделю = 1 пара в среднем.
- В панели показана средняя нагрузка группы. Отклонение от 1 пары/нед. требует проверки составителем. Недостающая пара автоматически не добавляется. Если последовательность содержит неоднозначное соседство (например три подряд), автоматический блок может не определиться для средней пары: проверьте и назначьте вручную.
- Подгруппы одного занятия всегда проходят одновременно у разных преподавателей.
- Перетащите ожидающую назначения подгруппу на уже занятую ячейку другой подгруппы той же группы у того же преподавателя: появится подтверждение объединения. Это также работает при перетаскивании существующей карточки занятия из сетки.
- При объединении отключается деление для всей группы. На каждом занятии сохраняется назначение целевой подгруппы; если его нет — имеющееся назначение. Остальные назначения удаляются. Общая численность не меняется. Проверяется вместимость аудитории для всей группы, возможно дополнительное подтверждение предупреждения. Отмена восстанавливает обе подгруппы.
- Занятия можно перетаскивать между преподавателями в пределах допустимого слота; блок из двух пар переносится целиком. Смена аудитории для такого блока также относится к обеим парам.

Формат проекта остался совместимым (schema 1). Перед обновлением сохраните JSON-проект. Реальные данные в архив и репозиторий не включены.

## Изменения 0.4.0

При импорте обязательны только ФИО преподавателя, шифр группы или название аудитории. Остальные колонки можно не сопоставлять, а ячейки — оставлять пустыми.

Неизвестные значения сохраняются как null: ставка, норма, численность, вместимость. Они не заменяются на 1 ставку, 12 пар или 24 студента/места. Должность остаётся пустой. Явно введённый ноль нормы сохраняется как ноль. Ошибочные заполненные числа по-прежнему требуют исправления.

Группа без времени создаётся с пустым списком занятий и остаётся в очереди. Частично указанные день, пара и неделя сохраняются; пустая неделя не становится автоматически обеими. Кнопка «Любой день» задаёт гибкость явно. Не полностью заполненная группа имеет отметку «Нужно заполнить»; при выборе открывается форма. Заполните численность, слоты и размеры подгрупп, если они включены, затем можно назначать занятия.

Карточки преподавателей и аудиторий с незаполненными параметрами можно сразу сохранить и позднее отредактировать. При назначении преподавателя без нормы показывается предупреждение; для аудитории без вместимости проверка мест помечается как невыполненная и требует явного подтверждения.

Пустые поля и незавершённые карточки сохраняются в JSON-проекте и Excel-снимке. Все изменения 0.3.0 (парные блоки, контроль средней нагрузки и объединение подгрупп с отменой) включены.


## Изменения 0.5.0

- Имя JSON и Excel берётся из названия расписания. Недопустимые символы имени файла заменяются подчёркиванием.
- В Chrome/Edge на HTTPS или localhost используется системный диалог сохранения JSON. Можно выбрать существующий файл; перед записью непустого файла приложение дополнительно подтверждает замену. Отмена диалога/подтверждения не отмечает проект сохранённым. Окно выбора появляется при каждом сохранении, чтобы явно выбрать место назначения.
- Если браузер не поддерживает showSaveFilePicker, выполняется обычное скачивание. Проверять наличие одноимённого файла на диске и гарантировать его замену в этом режиме приложение не может: поведение определяют настройки браузера. Для замены используйте Chrome/Edge или включите запрос места сохранения в настройках браузера.
- Общее расписание оформлено по листу «13 семестр 26-27» исходной кафедральной книги: исходные ширины столбцов, высоты строк, шрифты, границы и объединения заголовков; на преподавателя две строки: ФИО/группы и должность/аудитории. Шаблон содержит только оформление, без исходных значений и персональных данных. Седьмая пара субботы добавлена в том же стиле, поскольку исходник содержит только шесть. При превышении числа строк исходного шаблона повторяется образец двух строк преподавателя.
- Скрытый лист `_PROJECT` сохраняет полный рабочий проект, включая ограничения и нераспределённые карточки. Кнопка «Открыть» восстанавливает его из Excel на любом компьютере без JSON. Храните файл в формате XLSX; не удаляйте служебный лист. Восстановление не зависит от локальной автокопии.
- Ручные правки видимых листов Excel НЕ обновляют снимок `_PROJECT`: при открытии будет восстановлено состояние на момент экспорта. Для продолжения работы экспортируйте книгу редактором и передавайте её целиком. Google Sheets/Docs и повторное сохранение сторонними сервисами могут удалить служебный лист.
- Экспорт Excel предназначен для полного восстановления и содержит рабочие сведения на служебном листе, даже если он скрыт. Для распространения только итогового расписания используйте отдельную копию без служебных/рабочих листов; такую копию нельзя использовать для полного восстановления.


## Изменения 0.6.0

- При переносе блока изображение под курсором двойное. В сетке назначенный блок одного преподавателя/подгруппы растянут на две соседние ячейки; обе целевые ячейки подсвечиваются. Нажатие «Назначить» или перенос в любую половину допустимого блока назначает обе пары. Подгруппы сохраняют свою логику одновременного назначения и объединения.
- Справочники отсортированы по русскому алфавиту с естественным порядком номеров. Чернова закреплена первой среди преподавателей. Порядок исходных данных и сохранений не меняется.
- Поиск работает сразу при вводе; ё и е равнозначны. Фильтры групп: очередь, распределённые, деление, незаполненные, день и неделя (еженедельные занятия видны при выборе любой недели). Преподаватели: нагрузка ниже/выше нормы и незаполненные данные. Аудитории: вместимость от 25 и неизвестная вместимость. Показано число найденных карточек. Поиск и фильтры не сбрасывают несохранённые поля открытой карточки.
- Во время перетаскивания расписание прокручивается у верхнего/нижнего края видимой области, скорость возрастает при приближении к краю. Колесо направляется в расписание, когда курсор над ним. После отпускания, отмены или потери фокуса прокрутка останавливается.
- Проверки: 25 автоматических тестов; дополнительно DOM-проверки двойной карточки, поиска, фильтров, первого преподавателя, изображения переноса, прокрутки у края, колеса и завершения drag-and-drop. Проверки в реальном браузере с физической мышью не выполнены; нативные события drag/wheel могут отличаться между браузерами.
