# Проверка версии 0.4.0

- `npm test`: 15 тестов пройдены. Импорт по одному имени, пустые и частично заполненные свойства, JSON-восстановление, проверки заданных чисел, парные блоки, объединение и нагрузка.
- `npm run build`: успешно.
- Проверки в jsdom: карточки без численности и слотов видны в очереди, форма открывается без ошибок, пустые селекторы не подменяются значениями, после заполнения карточки возможно назначение. Преподаватель без ставки/нормы и аудитория без вместимости сохраняются с null. Excel-восстановление сохраняет null.
- Реальные teachers.xlsx, rooms.xlsx и groups.xlsx распознаются без заполнения отсутствующих свойств.
- Проверки предыдущего изменения: блок из двух пар, диалог аудитории на весь блок, отказ от объединения, подтверждение объединения и отмена пройдены.
- Реальная работа мышью и визуальный рендер Chromium в этой среде не проверялись; обработчики и формы проверены на уровне DOM.
- Docker не запускался.
