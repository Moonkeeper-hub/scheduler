# Патч 0.6.0 поверх 0.5.0

Сохраните текущий проект. Распакуйте содержимое патча в корень репозитория с заменой файлов, загрузите файлы в GitHub. Удалений и новых зависимостей нет.

На VPS:

```bash
(
set -eu
cd /opt/scheduler
git pull --ff-only
test -f src/ui-model.js
test -f src/drag-scroll.js
cp index.html /opt/moonkeeper-site/scheduler/
cp -R src public /opt/moonkeeper-site/scheduler/
)
```

Откройте сайт и нажмите Ctrl+F5. Caddy перезапускать не нужно.

Добавлено: двойные карточки двух пар через неделю (в очереди, справочнике, изображении переноса и сетке); явные подписи недель; алфавитная сортировка с Черновой первой; поиск и фильтры справочников; прокрутка сетки у края и колесом при переносе.

Формат проекта сохранён. Старые JSON и Excel открываются как раньше.

Проверены 25 тестов и DOM-сценарии интерфейса. Реальное перетаскивание физической мышью в браузере здесь не проверено.
